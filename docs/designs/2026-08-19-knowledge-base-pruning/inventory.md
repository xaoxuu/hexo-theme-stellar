# AI 知识库精简审计清单

## 分类规则

| 标记 | 含义 | 处理方式 |
| --- | --- | --- |
| `token` | 公共设计令牌、默认值和响应式档位 | 集中放在 `01-样式系统/design-tokens.md` |
| `contract` | 影响实现、兼容性、布局或验收的行为规则 | 保留在对应领域页面 |
| `public` | 用户可配置、可调用或可观察的接口 | 保留在配置/API/功能页面 |
| `implementation` | 可直接从源码查到的普通实现细节 | 删除或只保留源码入口 |
| `history` | 某次任务的取舍、实验和调试过程 | 保留在 `docs/designs/` |
| `duplicate` | 已在其他页面拥有权威来源的重复事实 | 改为链接引用 |

## 首批处理结果

| 页面 | 处理结果 |
| --- | --- |
| `01-样式系统/design-tokens.md` | 收敛为公共令牌、语义、响应式规则和事实来源 |
| `01-样式系统/styling-overview.md` | 收敛为样式架构、修改路径和判断规则 |
| `09-高级主题/custom-styling-overrides.md` | 收敛为配置/CSS 注入/组件覆盖入口与升级边界 |
| `docs/knowledge/README.md` | 增加信息分层、数值保留和单一事实源规则 |
| `AGENTS.md` / `stellar-theme-dev` | 增加 agent 写作与维护门禁 |

## 后续增量复查顺序

1. 布局系统：删除跨页面重复的卡片、导航和侧栏普通尺寸，只保留布局契约。
2. 内容系统与标签插件：保留标签参数、渲染结构和可观察行为，删除装饰性 CSS 快照。
3. 前端交互与外部集成：保留阈值、缓存、加载顺序和失败降级，删除普通动画属性。
4. 高级主题与性能：保留公开扩展入口和性能约束，删除实验过程与重复示例。

每次修改一个领域后运行 `python3 docs/knowledge/tools/verify.py`，并将跨页事实归并到唯一权威页面。
