# AI 知识库设计规范与精简方案

## 1. 问题与目标

当前知识库同时承担设计规范、行为说明、源码索引和历史变更记录，导致公共数值重复、普通 CSS 实现细节过多，agent 难以判断哪些内容是稳定契约。

本次调整将知识库收敛为三类信息：

- 设计语义：公共令牌及其适用范围；
- 行为契约：影响实现、兼容性或验收的规则与阈值；
- 修改依据：源码入口、配置入口和必要的决策说明。

具体 CSS 实现以源码为最终事实来源，历史取舍保留在 `docs/designs/`。

## 2. 设计规范

### 信息分层

| 位置 | 记录内容 |
| --- | --- |
| `AGENTS.md` / skill | 工作流程、门禁、完成条件 |
| `README.md` / `index.md` | 导航、适用范围、文档关系 |
| `01-样式系统/design-tokens.md` | 公共设计令牌、默认值、响应式档位 |
| 各领域知识页 | 功能行为、布局契约、公开配置和关键阈值 |
| `docs/designs/` | 单次任务的方案、取舍和历史过程 |
| 源码 | 具体 CSS、模板和 JS 实现的最终事实 |

### 数值保留

保留公共令牌、行为阈值、布局契约、公开配置默认值和兼容性所需的特殊值。普通选择器的 `padding`、`margin`、`font-size`、图标尺寸和一次性实验值，除非会影响布局、交互或验收，否则不在知识库中展开。

保留的数值必须带有语义和作用范围，例如：

```md
- `gap-base: 16px`：组件内部基础间距，供多数组件复用。
```

可能变化的数值标记为当前默认值，并链接实际定义；同一个事实只在一个页面解释，其他页面使用链接。

## 3. 影响范围

- 更新知识库入口维护规则；
- 收敛样式总览、设计令牌和自定义覆盖文档；
- 清理跨页重复的公共数值和普通 CSS 快照；
- 不修改主题代码、配置和对外行为。

## 4. 验收标准

- 公共令牌各有唯一权威说明；
- 保留的数值均能归类为 token、contract 或 public；
- 普通实现细节不再充斥总览页面；
- 文档引用有效，`python3 docs/knowledge/tools/verify.py` 通过；
- 后续知识库修改有明确的保留与精简规则。
