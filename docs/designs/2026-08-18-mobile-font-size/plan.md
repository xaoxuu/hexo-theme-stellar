## 风险与回退

- 移动端 rem 尺寸会随根字号增大，可能使部分卡片换行或高度增加；如实测过大，可仅回退移动断点的 `--fs-root` 调整。
- 不改变桌面端 root 的默认计算值，桌面布局可直接回退到原样式。
