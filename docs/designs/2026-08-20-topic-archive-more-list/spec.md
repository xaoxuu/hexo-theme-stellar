# 专栏更多文章归档样式与折叠展示方案

## 1. 问题与目标

- 专栏索引页的其他文章继续复用友链订阅 `.post-panel`，视觉语义与站内文章列表不一致。
- 最新文章封面保持不变；封面下方默认展示另外 3 篇文章，超过 3 篇时可展开并再次收起全部剩余文章。
- 其他文章改用归档页的 `MM-DD + 标题` 行样式，归档页原有行为与视觉不变。
- 专栏模块按各自最新文章的发布时间倒序排列；`publish_list` 继续只控制哪些专栏出现在索引页。

## 2. 技术方案

- 抽取 `archive_item.ejs`，统一归档页和专栏列表的文章行结构、链接兜底、日期格式与标题输出。
- `topic_card.ejs` 将 `topic.pages.slice(1)` 分为默认显示的前 3 篇与剩余文章；剩余文章使用原生 `<details>/<summary>`，不新增客户端脚本。
- `index_topic.ejs` 在渲染前按 `topic.homepage.date` 降序排列已上架专栏；无文章的专栏排在末尾，同日期保持 `publish_list` 原相对顺序。
- 将归档文章行 CSS 从 `#archive` 局部作用域提升为 `.post-list .archive-list` 公共作用域；专栏只维护容器内边距及折叠按钮状态样式。
- 新增 `btn.expand_posts`、`btn.collapse_posts` 三语言文案。固定阈值 3 不开放配置。

## 3. 影响范围

- 模板：归档列表行、专栏卡片。
- 样式：归档公共文章行、专栏折叠按钮。
- 国际化：简体中文、繁体中文、英文。
- 文档：文章列表知识库、验证登记、主站专栏 Wiki。
- 不修改 `scripts/`、浏览器 JavaScript 或公开配置。

## 4. 验证方式

- 覆盖专栏总文章数为 1、2–4、5 篇及以上的渲染分支。
- 检查展开数量、顺序、链接、日期、展开/收起状态及归档页回归。
- 检查专栏模块按最新文章发布时间倒序输出。
- 执行 `npm run check`、知识库核查和主工程 `npm run g`。
