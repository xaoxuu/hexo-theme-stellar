# 执行计划

1. [x] 抽取归档文章行 partial，并让归档页复用。
2. [x] 专栏默认渲染 3 篇其他文章，剩余文章接入原生折叠结构。
3. [x] 公共化归档行样式，新增专栏折叠按钮样式与三语言文案。

5. [x] 同步主题知识库、验证登记与主站 Wiki。
6. [x] 完成主题检查、知识库核查、主工程构建与页面验收；`npm run check` 的发版登记步骤受历史缺口阻塞，详见检查清单。

## 风险与回退

- 原生 `<details>` 在不支持的旧浏览器中可能直接展示内容；核心文章链接仍可访问，不影响内容可用性。
- 回退时恢复专栏原 `.post-panel` 输出即可，抽取后的归档行组件可独立保留。
