## 风险与回退

- 光斑只作用于链接，不改变链接外标题的布局与点击语义；搜索结果不启用 Tilt。
- 所有动态 API 调用均做能力检测；插件不可用时静态搜索不受影响。
- 卸载仅限定在搜索结果容器内，不影响页面上其它已挂载卡片。
