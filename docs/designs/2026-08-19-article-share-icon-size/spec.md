# 修复文章底部分享图标尺寸方案

## 1. 问题与目标

分享图标通过主题图标配置中的外部 SVG URL 以 `<img>` 输出，但分享栏只设置了网格列宽，没有约束图片尺寸，导致图标按固有尺寸显示并出现溢出或错位。

目标是让微信、微博、邮件和复制链接四个分享图标在分享栏内统一按 20×20 显示，不改变链接行为、图标来源或其它图片图标的样式。

## 2. 技术方案

- 在 `.article-footer .social-wrap a.social` 下为 `img` 设置 `width: 20px`、`height: 20px` 和 `display: block`。
- 仅影响文章页脚分享按钮中的图片，不修改通用 `img` 规则或图标生成逻辑。

## 3. 影响范围

- 影响文章、Wiki 等复用 `article_footer.ejs` 且启用分享栏的页面视觉尺寸。
- 不新增配置，不改变分享 URL、二维码或图标资源。
- 同步更新文章页脚知识库与核查记录。

## 4. 验证方式

- 执行主工程 `npm run g`，确认文章页模板可正常生成。
- 检查分享栏 CSS 选择器只命中 `.article-footer .social-wrap` 内的分享图标。
