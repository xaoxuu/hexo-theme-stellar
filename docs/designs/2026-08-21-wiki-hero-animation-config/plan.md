# 执行计划

1. 拆分 Wiki Hero 的静态背景与动画标记，建立安全的参数传递接口。
2. 将 Galaxy 固定参数改为逐 Canvas 规范化配置，并保持现有生命周期与失败降级。
3. 调整背景层级，补充客户端和模板标记测试。
4. 迁移主站示例配置，同步主题知识库、使用文档和核查记录。
5. 执行主题检查与主工程全量构建，记录结果。

## 风险与回退

- 非法参数逐项回退默认值，不阻断其它有效参数或 Hero 渲染。
- 图片与动画组合时，Canvas 默认透明；动态效果不可用时图片仍是完整静态回退。
- 旧 `background: galaxy` 不再识别为动画，使用方需要迁移到 `animation.type: galaxy`。
