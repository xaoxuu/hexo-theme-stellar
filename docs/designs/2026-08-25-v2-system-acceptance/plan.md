# 风险与回退

- npm 网络抖动：所有站点复用本轮私有 npm cache，但每个工程仍从真实 tarball 安装；失败不降级为源码软链。
- 跨平台路径：报告只记录相对站点 ID 与生成时绝对路径；fixture 使用 POSIX 相对目标，写入仍走 Node `path`。
- 迁移误变自动改写：迁移前/后树均作为显式 fixture 存储，脚本只复制指定版本，不推导字段映射。
- 人工结论边界：自动交付只推进到等待人工验收；若回退本切片，删除新增矩阵/fixture/文档即可，不影响运行时。
