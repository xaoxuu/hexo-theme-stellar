# 执行计划

## 实施步骤

1. [x] 在主题默认配置增加 `style.page_transition.enable`。
2. [x] 新增页面过渡 Stylus 组件，启用根页面和左栏过渡并处理减少动态效果。
3. [x] 同步主题知识库、核查记录与主工程 Wiki。
4. [ ] 执行主题检查、知识库核查、主工程构建与浏览器验收（自动化检查已完成，支持该能力的真实浏览器仍需人工确认动效观感）。

## 风险与回退

- 浏览器不支持跨文档 View Transition 时会忽略规则，自动回退普通整页导航。
- 站点作者可将 `style.page_transition.enable` 设为 `false` 完全关闭。
- 方案不接管导航或 DOM 生命周期，不会重新引入 PJAX 的脚本重执行与状态合并风险。
