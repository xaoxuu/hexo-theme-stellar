# 跨文档页面过渡方案

## 1. 问题与目标

PJAX 于 v1.35.0 移除后，Stellar 使用普通整页导航。浏览器会在每次切页时销毁并重建文档，即使左栏内容没有变化，也会跟随页面出现短暂闪烁。

目标是在不恢复 PJAX、不改变脚本生命周期的前提下平滑衔接同源页面，并让未变化的左栏保持视觉连续。关闭配置、减少动态效果或浏览器不支持时，继续使用现有整页导航。

## 2. 技术方案

- 复用现有 `style` 配置层，新增 `style.page_transition.enable`，默认开启。
- 使用 CSS `@view-transition { navigation: auto; }` 启用同源跨文档过渡，不新增 JavaScript或第三方依赖。
- 为 `.l_left` 设置固定的 `view-transition-name`，使左栏脱离根页面快照独立过渡；根页面和左栏统一使用主题常用的 `0.2s ease-out` 动效语义。
- 在 `prefers-reduced-motion: reduce` 下将 `navigation` 设为 `none`。

## 3. 影响范围

- 主题默认行为增加渐进增强的同源页面过渡；配置关闭或不支持该 CSS 能力时行为不变。
- 不修改 PJAX、history、滚动恢复、评论初始化、数据服务或插件重入逻辑。
- 跨域导航、刷新、地址栏导航和页内锚点不由跨文档过渡接管。
- 同步更新页面导航知识库、核查记录与主工程 Wiki 高级设置。

## 4. 验证方式

- 检查默认开启时构建 CSS 包含 `@view-transition` 与 `leftbar` 命名区域，关闭时不输出相关规则。
- 运行主题检查、知识库硬事实核查与主工程全量构建。
- 在支持该能力的 Chromium / Safari 检查首页、文章、Wiki、分类及前进后退；在不支持浏览器和减少动态效果模式检查降级路径。
