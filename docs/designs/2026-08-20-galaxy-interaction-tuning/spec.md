# Wiki Galaxy 辉光与鼠标交互调整

## 1. 问题与目标

- 默认辉光强度 `0.5` 会让高密度星点过于显眼，削弱 Hero 内容层级。
- 鼠标只产生整体视差，附近星点缺少局部反馈。
- 目标是降低辉光存在感，并增加克制的鼠标排斥，不改动密度、速度、色相、闪烁、旋转和生命周期。

## 2. 技术方案

- 复用现有 `params`、着色器鼠标排斥分支、平滑鼠标坐标和 `uMouseActiveFactor` 淡出机制，不新增配置项或公开接口。
- `glowIntensity` 从 `0.5` 调整为 `0.2`。
- `mouseRepulsion` 从 `false` 调整为 `true`，`repulsionStrength` 从 `0` 调整为 `0.1`。
- `autoCenterRepulsion` 继续为 `0`，不启用中心自动排斥。

## 3. 影响范围

- 仅影响 `background: galaxy` 的默认视觉和鼠标反馈。
- Canvas 仍不接收指针事件，Hero 链接和按钮命中不变。
- 减少动态效果、可见性暂停、视口观察、WebGL 失败降级和销毁逻辑不变。

## 4. 验证方式

- 运行主题 lint 和主工程全量构建，确认 Galaxy 脚本转译、压缩与按需生成正常。
- 核对固定参数和着色器分支，确认启用弱排斥、降低辉光且未开启中心排斥。
- 浏览器视觉效果与交互强度由用户预览验收。
