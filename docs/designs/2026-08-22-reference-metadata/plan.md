## 风险与回退

- 风险：Schema 对开放的第三方参数袋约束过严。处理：仅校验参数袋为普通对象并允许其内部上游字段。
- 风险：动态默认值被错误固化。处理：用 `derived`、`inherited`、`computed` 元数据表达来源，不伪造字面量。
- 风险：新增运行期结构校验改变合法模型行为。处理：只校验当前已经输出的结构和类型，用四类现有行为测试回归。
- 回退：删除 Schema 校验、Reference 生成入口与产物即可恢复到 #695–#698 的模型接缝，不需要配置或内容迁移。
