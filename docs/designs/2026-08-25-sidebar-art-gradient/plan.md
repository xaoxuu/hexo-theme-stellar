# 执行计划

## 实施步骤

1. [x] 扩展 Theme Schema 与四颜色调色板校验器，补充解析和错误测试。
2. [x] 在 Stylus 配置投影与 `.sidebg` 中实现分模式调色板、多层渐变和降级顺序。
3. [x] 生成默认配置、Reference 与字段审计。
4. [x] 同步知识库、公开 Wiki 与方案记录。
5. [x] 按 F1 完成 Schema 生成/检查、定向单测、知识库和规范引用核查。
6. [x] 参照 xaoxuu.com 线上旧版校准推荐色相，缩小三层光晕并完成回归验证。
7. [x] 校准默认 HSL，并在最终契约中保留浅色、深色两套显式调色板。
8. [x] 将主题默认改为无图片 Glass 渐变、100px 模糊、完整透明度与 a50 遮罩。
9. [x] 新增 `type: gradient | image | color` 显式背景选择，移除空数组开关与隐式降级。

## 风险与回退

- 渐变函数不受旧浏览器支持时，以首个色相生成的模式基础色回退。
- 需要图片时显式设置 `type: image` 与 `image`；缺少选中类型的参数时不自动切换到其它背景。
- Card 表面通过既有高特异性规则隐藏背景，不改变其布局和交互令牌。
